# LifeOS · 个人生活管理

手机优先、可离线使用的个人生活节奏管理 PWA。管理睡眠、工作、健身、阅读、英语、IT/AI 学习，并支持妻子电话、临时工作等突发**中断**后的任务重排，**睡眠受保护**，不熬夜补任务。

- React + TypeScript + Vite，无后端、无云同步、无外部分析。
- 中文界面，移动端优先，可添加到手机主屏幕。
- 所有数据保存在本机，支持 JSON 导出 / 导入。

## 安装与启动

需 Node.js 18+（推荐 20/22/24）。

```bash
npm install
npm run gen:icons   # 生成 PWA 图标（public/icons/）
npm run dev         # 开发服务器，默认 http://localhost:5173
```

手机访问：让手机与电脑同网段，用 `npm run dev`（Vite 默认监听 0.0.0.0），手机浏览器打开 `http://<电脑IP>:5173`。

> **本机环境备注（Sangfor kysec）**：该机器开启了 kysec 安全模块，会拦截**新解压的脚本直执行**（带 shebang 的 npm bin shim，如 `tsc`/`vite`/`vitest`），表现为 `EACCES`；但**原生 ELF 二进制（esbuild）和“用 `node` 读 JS 文件运行”不受影响**。因此：
> - 若 `npm install` 在 `esbuild` 的 postinstall 报 `EACCES`，改用 `npm install --ignore-scripts`（已不影响功能，原生二进制仍可用）。
> - 本仓库的 `package.json` 脚本已改为通过 `node node_modules/...` 直接调用底层 JS 入口，`npm run dev / build / test` 在 kysec 下均可正常运行。

## 构建与部署

```bash
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 本地预览构建结果
```

`dist/` 是纯静态文件，可部署到任意静态托管：Vercel / Netlify / GitHub Pages / Cloudflare Pages / Nginx 等。部署为 SPA 时需将所有路由回退到 `index.html`（本仓库的 Service Worker 已配置 `navigateFallback`）。

### 安装到手机主屏幕

1. 用手机浏览器打开部署后的地址（建议 HTTPS，PWA 才可安装）。
2. Android Chrome：菜单 → “添加到主屏幕”。iOS Safari：分享 → “添加到主屏幕”。
3. 安装后离线可继续查看与打卡（首次打开后资源已被 Service Worker 缓存）。

## 数据备份与恢复

- **导出**：设置 → 数据备份 → “导出 JSON 备份”，下载文件。
- **导入**：设置 → “导入 JSON（覆盖）”，选择备份文件；格式错误会提示且**不破坏原数据**；导入为覆盖操作，会二次确认。
- **清空**：设置 → “清空本地数据”，二次确认后恢复默认模板。

数据存储在浏览器 `localStorage`（键 `lifeos:data:v1`）。清除浏览器数据会丢失，请定期导出备份。

## 功能概览

### 今日
- 日期、当前时段、完成进度、时间线。
- “开始中断”主按钮与“快速打卡”。
- “设为休息日”“低能量日”开关。
- 进行中的中断显示大号计时器，刷新不丢失。

### 中断模式（核心）
- 选择类型：妻子电话 / 家庭事务 / 临时工作 / 其他，可填备注。
- 结束后自动列出**受影响的待办任务**，并按规则给出建议：
  - 睡眠、工作、健康、家庭等**受保护**任务：只能继续或缩短，不移动；睡眠绝不压缩。
  - 阅读、英语、IT/AI 等**可移动**学习任务：可移动到当日弹性时段、缩短为最低版本、或跳过。
- **睡眠保护**：移动只能落在 07:00–23:00 内的空闲缝隙，绝不越过就寝时间；无空隙则建议缩短或跳过，**不熬夜补**。
- 调整需用户**逐项确认**后生效，不会自动重写计划。
- 妻子电话为中性事件，不显示失败、惩罚或红色警告。

### 计划
- 本周概览（训练 / 晚间学习按星期轮换）。
- 任务模板编辑：名称、时间、时长、分类、优先级、每天/按星期重复、固定时段、低能量版本。

### 复盘
- 今日与本周统计：完成率、运动次数、阅读分钟/天数、英语次数、IT/AI 分钟、中断次数与时长。
- 最近 7 天完成率趋势。
- 睡眠手动记录（实际就寝 / 起床，跨夜时长）。
- 每周复盘：做得好的事、阻碍、下周只改进的一件事。

### 设置
- 作息、工作与通勤、学习频率、低能量默认时长、主题（跟随系统/浅色/深色）。
- 数据备份与隐私说明。

## 项目结构

```
src/
  types/          数据模型
  data/           默认作息模板与设置（来自 02_用户作息与计划配置）
  lib/            时间、日程生成、中断重排、统计、存储、ID（纯逻辑，含单元测试）
  state/          Context + Reducer + localStorage 持久化
  components/     UI 组件（任务卡、中断流程、抽屉、导航、图标）
  pages/          今日 / 计划 / 复盘 / 设置
  *.test.ts       关键业务逻辑测试
```

## 已知限制

- 首版无账号、无后端、无云同步，数据仅本机；换设备需手动导入备份。
- 不自动检测睡眠、不读取通话记录；中断由用户手动开始与结束。
- 中断重排仅处理“与中断时段重叠”的待办任务；不自动顺延后续固定任务（固定任务保持原时间）。
- 学习频率为目标值，不强制；可在计划中按星期配置具体日子。
- 浏览器通知非核心功能；无通知权限时全部功能仍可用。

## 隐私

不接入外部分析、广告、云端 AI；不向任何第三方上传个人数据。所有计算与存储均在设备本地完成。
